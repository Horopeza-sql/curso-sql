💬 2. Cómo retomar en un chat nuevo

▶

Paso 1 — Abrir la terminal

cd C:\Users\horopeza\Documents\curso-sql
git pull

Paso 2 — Copiar el estado actual

notepad PROYECTO\00-ESTADO-ACTUAL.md

Copia todo el contenido del archivo.

Paso 3 — Copiar el último historial

dir PROYECTO\HISTORIAL

Abre el último archivo con notepad PROYECTO\HISTORIAL\YYYY-MM-DD-sesionN.md y copia el contenido.

Paso 4 — Abrir un chat nuevo

Pega:

  1. El contenido del 00-ESTADO-ACTUAL.md
  2. El contenido del último historial
  3. Un mensaje como: "Continuemos con el proyecto. Aquí está el estado actual y el último historial."

🗣️ 4. Qué pedirle a la IA

▶

Mensaje de apertura

Continuemos con el proyecto "Programa de Análisis de Datos desde Cero".

Aquí está el estado actual:
[pegar 00-ESTADO-ACTUAL.md]

Aquí está el último historial:
[pegar último historial]

Por favor:
1. Confirma que tienes el contexto completo.
2. Dime cuál es el siguiente paso según el estado actual.
3. No me des la razón en todo: si algo no te parece, dímelo con argumentos.
4. Prioriza calidad sobre velocidad.

Reglas que la IA debe seguir

  • ✅ Ser honesta, no decir "sí" a todo.
  • ✅ Si algo no le parece, decirlo con argumentos.
  • ✅ Si algo se puede mejorar, proponer alternativas.
  • ✅ No dar respuestas genéricas.
  • ✅ Si no sabe algo, decir "no lo sé".
  • ✅ Priorizar calidad sobre cantidad.
  • ✅ Recordar los pendientes cuando sea relevante.
  • ✅ Avisar ANTES de seguir si detecta un error.

✅ 7. Decisiones tomadas

▶

Arquitectura

  • 11 secciones: Introducción y Entorno, Fundamentos de BD, Consultas Esenciales, Análisis y Agregaciones, Relaciones y Modelado, Diseño y Objetos, SQL Avanzado, Calidad y Trabajo Profesional, Administración Básica, Proyecto Final, Referencia Rápida.
  • 2 grupos: "Programa" y "Fase 1 · SQL".
  • Sin números en el menú visible.

Contenido

  • Plantilla pedagógica de 13 pasos: Objetivo → Problema → Cuándo → Concepto → Sintaxis → Ejemplo → Errores → Práctica (3 niveles) → Validación → Aplicación → Criterio de éxito → Resumen → Siguiente.
  • Práctica en 3 niveles: 🟢 Guiada / 🟡 Autónoma / 🔴 Caso de negocio.
  • Proyecto transversal: Ventas / Facturación / Cobranza.
  • 3 entornos de datos: world → employees → proyecto propio.
  • Regla pedagógica: "Tratar lo menos posible el código que aún no se ha visto."

Decisiones firmes

  • MySQL 8.4 LTS (no 9.x).
  • Sin cifras de salario ni afirmaciones de mercado sin fuente.
  • No es un curso de DBA ni de backend ni ERP.
  • Enlaces externos en misma pestaña (pendiente revisar).
  • Mermaid descartado por ahora.
