# Fase 1 · SQL

Bienvenido a la **Fase 1** del Programa de Análisis de Datos desde Cero.

Esta fase te enseña **SQL aplicado al análisis de datos**: desde consultas básicas hasta análisis avanzado, con un proyecto empresarial real que construirás paso a paso.

---

## 🎯 ¿Qué aprenderás en esta fase?

- Consultas SQL desde cero.
- Análisis con agregaciones y funciones.
- Relaciones entre tablas con JOIN.
- Subconsultas, CTEs y Window Functions.
- Diseño y objetos de bases de datos.
- Calidad y validación de datos.
- Administración básica de MySQL.

**Al terminar, tendrás un proyecto funcional que podrás mostrar como portafolio.**

---
