# 🗺️ Roadmap del Programa

Este curso forma parte de un **programa completo de Análisis de Datos desde Cero**. Cada fase es independiente y se puede estudiar por separado, pero juntas forman un recorrido integral.

---

## 🎯 Visión del programa

Convertirte en **analista de datos** desde cero, dominando las herramientas más demandadas del mercado:

- SQL para consultar y transformar datos.
- Python para automatizar y analizar.
- R para estadística avanzada.
- Power BI y Tableau para visualización.
- ETL para preparar datos.

---

## 📚 Fases del programa

### ✅ Fase 1 — SQL para Análisis de Datos *(disponible)*

**Estado:** 🚧 En construcción.

**Qué aprenderás:**
- Consultas básicas y avanzadas.
- JOINs, subconsultas, agregaciones.
- Window Functions y CTEs.
- Creación de objetos de BD.
- Administración básica.

**Dirigido a:** cualquier persona que quiera empezar con datos sin experiencia previa.

---

### ⏳ Fase 2 — Python para Análisis de Datos *(próximamente)*

**Estado:** 📅 Planificada.

**Qué aprenderás:**
- Tipos de datos, estructuras y POO.
- Manejo de archivos.
- Pandas y NumPy.
- Proyectos reales de análisis.

---

### ⏳ Fase 3 — R para Análisis de Datos *(próximamente)*

**Estado:** 📅 Planificada.

**Qué aprenderás:**
- Vectores y dataframes.
- Funciones `apply`.
- Gráficos personalizados.
- Análisis exploratorio.

---

### ⏳ Fase 4 — Visualización con Power BI y Tableau *(próximamente)*

**Estado:** 📅 Planificada.

**Qué aprenderás:**
- Power Query y DAX.
- Dashboards interactivos.
- Mapas geográficos y analíticos.
- Storytelling visual.

---

### ⏳ Fase 5 — ETL y Data Studio *(próximamente)*

**Estado:** 📅 Planificada.

**Qué aprenderás:**
- Limpieza y transformación de datos.
- Reportes en Data Studio.
- KPIs y blending de fuentes.

## 🎁 ¿Por qué estudiar el programa completo?

| Solo SQL | Programa completo |
|---|---|
| Consultas básicas | Análisis end-to-end |
| Perfil junior | Perfil senior |
| Sueldo base | Sueldo superior |
| Una herramienta | Stack completo |

**El programa completo te convierte en un analista de datos integral.**
